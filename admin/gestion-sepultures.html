⚙ Paramètres — Administration
Accessible uniquement à l'administrateur
👥 Gestion des utilisateurs & mots de passe
📐 Capacité des concessions (nombre de lots)
💡 Ajuste le nombre de lots (ou niches pour C1N/C1S) disponibles dans une concession — utile si de nouveaux lots sont ajoutés physiquement, par exemple dans 1010 ou 1011.
⚖️ Règle des lots (cercueils / urnes)
💡 Définit combien de cercueils et d'urnes sont autorisés sur un même lot, selon la date de changement de règle. Un lot suit l'ancienne règle dès qu'un défunt y a été inhumé avant cette date.
⛪ Informations du cimetière / client
💡 Ces informations apparaissent sur le portail public, les fiches, les certificats et les reçus. Changez-les pour chaque nouveau client.
📭
Portail public jamais généré
Cliquez sur « Générer portail public » pour publier vos données.
🚀 Publication automatique — Portail famille (Netlify)
Une fois configuré ici, un clic sur « Portail famille » dans le menu de gauche publie automatiquement la nouvelle version sur votre site Netlify — plus besoin de télécharger le fichier et de le déposer manuellement. Le Site ID se trouve dans Netlify sous Site configuration → General → Site details, et le jeton d'accès personnel se crée sous User settings → Applications → Personal access tokens.
📁 Profils cimetières — Changement de client
Sauvegardez la configuration de chaque cimetière client. Chargez-en un pour basculer rapidement d'un client à l'autre.
⏱ Sauvegarde automatique programmée Désactivée
💾 Sauvegarde automatique vers un fichier JSON téléchargé à intervalle régulier. Les données sont aussi sauvegardées en continu dans le navigateur.
Dernière sauvegarde : —
Sauvegarde navigateur — Continue même sans sauvegarde programmée. Vos données sont conservées automatiquement à chaque modification.
Téléchargement — Crée un fichier JSON horodaté dans votre dossier Téléchargements à chaque intervalle.
🏛 Gestion multi-cimetières 🔒 Concepteur
📋 Gérez plusieurs cimetières dans une seule application. Chaque cimetière conserve ses propres données, configuration et registre de défunts.
